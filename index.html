Good to know

Before you throw.

Short answers to the practical questions.

What does Throw run on?

Throw is for Windows x64. The per-user installer doesn’t require admin rights or an additional runtime. This is preview software, and the installer is currently unsigned.

Why does Windows warn me about the installer?

The installer is unsigned, so Windows may show a publisher or reputation warning. That warning is expected for an unsigned build, not a reason to bypass protections. Only install software you trust; inspect the source and release details before running it.

Does it send telemetry or run a web runtime?

Throw uses native Windows controls and is built with Rust. It does not include Electron, a WebView, a .NET runtime requirement, or a background telemetry process. Browser bookmark discovery and local launch history are opt-in features.

Can I change the shortcut or appearance?

Yes. The default shortcut is Ctrl+Alt+Space; alternatives include Alt+Space and Ctrl+Shift+Space. You can choose a custom shortcut and a theme in Throw’s settings.

Is Throw related to Flow Launcher?

Throw originated as a Flow Launcher fork and retains that project’s credit. It is an independent project, not affiliated with Microsoft or Flow Launcher. It is MIT licensed and open source on GitHub.

Can I download a portable build?

There is no verified portable download link here. Check the project’s source repository and release page for current build options.

What does the demo on this page do?

It filters a small set of examples in your browser and previews selections as text. It does not access your files, run apps, execute commands, or open search URLs. The actual Windows app has those capabilities with the permissions and confirmations described in its documentation.
